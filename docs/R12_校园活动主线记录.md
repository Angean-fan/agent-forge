## 设计

- **按实体权限**：全局 `permissions` 为默认；`entity_permissions` 覆盖指定实体。校园：Activity 成员只读（**成员不得发布**），Enrollment 成员可创建（**可报名**）、管理员只读/删除。
- **固定断言冻结**：Runner 校园场景为**平台固定**，随规格冻结；不由编码 Agent 编辑。
- **Finder 审计**：复用 R06C 的只读候选层，把候选/复用/未覆盖规则**留痕到交付包与事件**，满足“报告额外列出”。
- **回归保护**：原 Task 场景断言与生成路径不变；`status_guards`/`entity_permissions` 空时不参与哈希。
