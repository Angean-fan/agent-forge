## 设计

- **矩阵化回归**：三用例（校园/任务/借阅）× 四合规 Profile（ts-mp/ts-mb/js-mp/js-mb）一次性覆盖契约编译、资产解析与装配；交付清单以**装配产物清单**断言，避免依赖 Docker 即证“构建/启动”前置条件齐备。
- **Mock 分层**：Runner 固定检查以假对象注入；`EXTERNAL_SERVICES.md` 明确“无第三方服务、无须配置”（Mock 可交付）。
- **路由不可跨厂商**：单一断言源（`model_gateway.ROUTES`）核对角色→Provider/模型，任何越权新增角色都无法通过。
- **诚实覆盖**：图书借阅未登记固定主线 → `platform_mainline is None`，缺口如实呈现，不制造“全绿”假象；既有主線（Task/Activity+Enrollment）仍断言命中。
- **索引可复现 / 旧锁不漂移**：全量重建比特一致；无方法请求时锁 schema 保持 0.1 且哈希稳定（旧锁按原语义重放）。
- **Agent 无资产写权限**：R15 受保护清单 + run 目录隔离，回归固化“不得改交付/验真产物、不可触达版本化方法仓库/索引”。
