## 设计

- **静态路由**：`ROUTES` 中仅 `user_interaction`（`deepseek_official` / `deepseek-flash`）`enabled=True`；`technical_planning/coding/complex_repair`（Qwen）仅占位，`enabled=False` → 调用即抛 `MODEL_ROLE_DISABLED` 且**不触发外部请求**。
- **账本**：`model_call(call_id PK, model_role, provider, model, project_id, draft_id, run_id, thinking_mode, request_id, price_version, reserved_micro, cost_micro, input_tokens, output_tokens, status, error_class)`；金额为整数**微单位**（1 元 = 1e6 微）。
- **预留 → 调用 → 结算**：`reserve` 先校验角色/草稿次数与频率（`AGENTFORGE_DRAFT_MAX_CALLS`、`AGENTFORGE_DRAFT_MIN_INTERVAL_SECONDS`）与预算（`available = 预算 - 已结算 - 在途预留`，预算 `AGENTFORGE_PROJECT_BUDGET_MICRO`，默认 10 元），不足即抛 `BUDGET_EXCEEDED`（**不调用**）；`invoke` 仅在预留成功后调用客户端，成功后按真实 usage 结算，失败则记 `UNKNOWN` 并 `commit` 保留预留供对账。
- **价格**：来自外部 price 文件（`AGENTFORGE_PRICE_FILE`，含 `version` + 每模型每百万 token 微价）；**不硬编码**。缺价格 → 保守预留（`AGENTFORGE_DEFAULT_RESERVE_MICRO`）且 `price_version=UNKNOWN`、结算后仍 `UNKNOWN`。
- **幂等结算**：`settle` 对已 `SETTLED` 的 `call_id` 直接返回，不重复计费。

## 真实 DeepSeek 调用：**NOT_RUN**（环境网络限制）

- **本环境 Python TLS 无法与 `api.deepseek.com` 完成握手**：`ssl.SSLEOFError: UNEXPECTED_EOF_WHILE_READING`（`urllib`）；已尝试关闭沙箱与注入系统信任库（`truststore`）均同样失败。
- **curl 可通**：`POST https://api.deepseek.com/chat/completions`（`model: deepseek-flash`，Bearer 密钥）→ **HTTP 200**，返回 `model=deepseek-flash` 与真实 `usage{prompt_tokens,completion_tokens,total_tokens,reasoning_tokens,...}`。即**端点/密钥/model ID 有效**，仅 Python 客户端 TLS 在本环境被中断。
- 因此 M21 的真实网关调用记 `NOT_RUN`；护栏逻辑由假客户端测试全覆盖。需在允许 Python 出网的环境（或改用可握手客户端）再做一次真实端到端调用（M22 前置探针）。
