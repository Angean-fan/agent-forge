## 已实现（不依赖 Docker，已实测）

1. **内部认证**：除 `/health` 外所有请求须带 `X-Runner-Token`（env `RUNNER_TOKEN`）；缺失/错误 → 401。
2. **固定任务白名单**：`tasks.py` 只登记 `backend_test` / `backend_build` / `frontend_build`，调用方**不能传入命令或脚本**；非白名单任务 → 422。
3. **路径安全**：工件目录必须是 `RUNNER_WORK_ROOT` 之内的相对路径；`..`/绝对路径/符号链接逃逸/不存在 → 422。
4. **隔离契约**（`container.build_run_argv`，以单测锁定）：
   `--network none`、`--read-only` + `--tmpfs /tmp`、`--user 1000:1000`、`--cap-drop ALL`、
   `--security-opt no-new-privileges`、`--pids-limit 256`、`--memory 2g`、`--cpus 2`、`--rm`；
   **只挂载**本次 run 的工件目录（`dst=/workspace`）；**无** `docker.sock`、平台库、模型 Key 挂载；
   执行 = **固定 argv**（无 `sh -c`），不暴露任意 shell。
5. **诚实降级**：执行环境不可用时 `/run` 返回 `status=NOT_RUN`，不伪造成功。

测试：`runner` **10 passed**（认证/白名单/路径/降级/隔离参数契约）；平台 `uv run --locked pytest` → **120 passed**；两者 `ruff` 全绿。
