## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：只为**已通过全部代码必需验收**的生成项目提供**短时**在线预览，结束后自动释放隔离实例。
- **Context**：依赖 R27 的 Demo P0 基线与 Runner；FR09、§9 规定**演示数据、随机授权地址、默认 15 分钟回收**。
- **Constraints**：非已验证产物**不得**开启；不向公网任意运行未知代码；**停止预览不删除源码**；
  预览**不能混用**用户生产数据或第三方正式凭据。
- **WhenDone**：授权用户可访问短时预览；非授权者拒绝；15 分钟到期清理容器与数据，ZIP 仍可下载。

## 设计

- **只有已验收产物**：以 E04 的 `code_delivery_status` 为门禁；未完成/失败/在途一律拒绝。
- **随机地址即凭据**：token 不可枚举、常数时间比较；网关对无效 token 一律 404，避免枚举与存在性泄露。
- **回收不动产物**：预览会话独立于源码 ZIP；停止/到期只释放实例与预览数据。
- **隔离**：预览环境仅演示占位值，**绝不**注入秘密/正式凭据/生产数据。
- **不外溢执行**：本环境不接入隔离实例，网关只做授权，**不公开运行未知代码**。

## 需开发者确认（阻塞真实预览运行时，**不猜测**）

按执行要求"遇到 Runner 权限、运行环境不确定时暂停并请求确认"：

1. **隔离实例基础设施**：预览容器的隔离方式（独立网络/资源限额/只读挂载）、端口与随机地址的暴露边界；

4. **演示数据来源**：确认使用生成的 Mock/演示数据，不接入任何用户生产库或第三方正式凭据。
