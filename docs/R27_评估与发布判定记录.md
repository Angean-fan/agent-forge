## 设计

- **不伪造、不降级**：Runner 不可达时**不**用桩结果冒充“通过”；9 次全部 NOT_RUN，报告明确“未达到目标”。
- **阈值用成功数**：`goal_met = 通过数 ≥ 7 且校园成功`；失败/NOT_RUN **不计**成功；关键词命中**不算**覆盖（四层分离）。
- **成本口径双报**：成功项目平均成本 + 总费用/成功次数；成功为 0 → “不可计算”（不写 0 冒充）。
- **可追溯**：每次 run 记录索引快照、已锁方法、拒绝原因、Agent 调用量与“复用 vs Patch”路径。
- **确定性装配默认 0 模型调用**：生成期 DeepSeek/Qwen 角色默认关闭；如需启用由环境变量显式开启（成本随之为真实用量）。
