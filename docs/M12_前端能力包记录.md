## 设计要点

1. **参数只能来自经校验的契约**：`build_params` 派生实体名/复数路径/视图与可写字段及 TS 类型；接口路径来自契约的路由（`/tasks`）。不接受模型或任意字符串。
2. **只生成 TS**：SFC + `.ts`，无 JS 变体。
3. **不渲染未净化 HTML**：全部使用 Vue 模板（Element Plus 组件）插值，无 `v-html`；模型返回内容按普通文本处理。
4. **不设服务端秘密**：请求层只带 Bearer 令牌（来自登录态），无密钥硬编码。
5. **接入模板登录/路由**：视图依赖路由守卫（`requiresAuth`）与 `request()`（自动带 Bearer）；模板路由经 `modules/*.ts` 自动加载（能力包不修改模板路由文件）。
6. **确定性渲染**：与 M11 同一渲染器（`materialize` 泛化，复制基础模板后渲染，不改原模板）。
