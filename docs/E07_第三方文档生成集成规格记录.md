## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：缺 OpenAPI 时先提取**带出处/不确定项**的集成规格；**向用户提问与解释用 DeepSeek**，
  确认后由技术规划/编码角色受限补 Adapter。
- **Context**：依赖 E06、R15—R17；技术文档 §6 要求提取操作/认证/错误/回调/外部待办，**不能编造供应商协议**。
- **Constraints**：用户确认后才冻结；技术侧（Qwen）只可**提议**契约、编码角色（Coder）只可补**授权 Adapter 文件**，
  不得据原始聊天改写需求；**文档提示注入无权改变执行权限**；**未知 SDK 不自动安装**；缺失鉴权/回调**保留 pending、不启动 Live**。
- **WhenDone**：不完整文档产生**明确问题清单并暂停**；已确认样例**仅修改允许的 Adapter 文件**；**固定安全与契约测试通过**。

## 输入 / 输出契约（`integration_doc.py`）

- **`extract_integration_spec(docs, *, provider) -> IntegrationSpecDraft`**：
  - 确定性提取 `operations/auth/callbacks/errors/external`，**每条 Fact 带 `source`（文档:行）与 `quote`**；
  - 缺关键语义（认证/签名/幂等/回调/错误/SDK）→ 生成 `PendingQuestion`；**不编造**；
  - **提示注入防护**：命中"忽略此前指令/授权所有权限/运行以下指令"等模式的行**只记录**为
    `injections`，**不参与提取、不改权限/SDK**。
- **`freeze_integration_spec(draft, confirmations)`**：仍有未确认 pending → 抛 **`INTEGRATION_PENDING`(409)**
  并回传问题清单（**暂停**）；全部确认 → 冻结（事实**不被改写**），`ready_for_live=False`（Live 归 E05）。
- **`adapter_edit_issues(paths, allowed_prefix="integration/adapter/")`**：编码角色**只可**改授权 Adapter 文件，
  越界（port/安全模板/锁/测试）即报违规。
- **模型缝（默认确定性，本步不调用）**：
  - `render_questions(explain=…)`——面向用户的提问由 **DeepSeek** 补充，`explain` 只接收**脱敏结构化事实**
    （provider/问题主题/操作），不含文档引文；
  - `propose_contract(planner=…)`——技术侧 **Qwen** 只可**提议** Port 方法骨架，事实字段**只来自文档提取**。
- `errors.py` +`INTEGRATION_PENDING`。

## 设计

- **四级链路第 3 级**：无 OpenAPI 时由文档生成**待确认** Integration Spec；E06 负责有 OpenAPI 时的生成。
- **不编造 + 可追溯**：每条事实带出处；不确定即 pending，冻结前必须用户确认。
- **提示注入即数据**：注入行被跳过提取并记为安全发现——**不能**改变允许域名/权限/SDK。
- **最小授权**：编码角色仅可改 `integration/adapter/**`；不改认证模板、资产原件、锁文件、平台验收断言。
- **模型边界**：用户交互用 DeepSeek（只述脱敏事实）、技术提议用 Qwen（只提议、不改需求）、编码用 Coder（限 Adapter 文件）。

## 剩余风险 / 下一步

- **模型缝未实测**：DeepSeek 提问/解释与 Qwen 契约提议为可注入缝，真实调用与路由断言待带预算里程碑（不猜测）。
- **提取为规则式**：面向代表性文档；更复杂的语义（多版本、条件错误码）会更多地落到 pending，交用户确认。
- **未接入生成链路**：冻结的 Integration Spec 尚未驱动 Adapter 生成/装配（随装配接入，E01—E07 一致零漂移）。
