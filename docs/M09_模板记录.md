## 一、Profile 修正（0.1 → 0.2）

M09 验证发现 **`vue-tsc 3.3.13` 与 `typescript 7.0.2` 不兼容**：TS 7 不再导出 `./lib/tsc`，
`vue-tsc --noEmit` 报 `ERR_PACKAGE_PATH_NOT_EXPORTED`。按 M08"版本以兼容性测试结果为准"，
将 `typescript` 修正为 **5.9.3**（`vue-tsc` 声明 `typescript>=5.0.0`，实测通过）。
依"Profile 一经发布不可原地覆盖"，新增 `demo-ts-mp@0.2`，保留 `0.1` 不改；平台 `spec.py`
常量、样例 spec、`profiles/README.md` 同步更新为 0.2。

## 二、后端（Spring Boot 3.5.16 / Java 17 / MyBatis-Plus 3.5.17 / Flyway / MySQL）

- 结构：`controller`（Health、Auth）、`service`（Auth、User）、`mapper`（AppUserMapper）、`entity`（AppUser）、`dto`（LoginRequest）、`vo`（UserView、LoginResponse）、`config`（SecurityConfig、AdminUserInitializer）、`exception`（GlobalExceptionHandler、ApiException、ErrorCode）、`security`（JwtService、JwtAuthenticationFilter）；`resources/db/migration`。

- 测试：`mvn clean package` → **BUILD SUCCESS**，`Tests run: 4, Failures: 0`（健康公开、登录成功、登录失败 401、`/me` 鉴权）。测试用 H2（`application-test.yml`）。

## 四、启动与模板登录（实测）

`java -jar target/backend-0.1.0.jar --spring.profiles.active=local`（H2 内存库，MySQL 兼容模式）后：

| 请求 | 结果 |
|---|---|
| `GET /api/health` | `200 {"status":"ok","service":"agentforge-template"}` |
| `POST /api/auth/login`（admin/admin123） | `200`，返回 151 字符 JWT，`user={id:1,username:admin,role:ADMIN}` |
| `POST /api/auth/login`（错误口令） | `401` |
| `GET /api/auth/me`（带 Bearer） | `200 {"id":1,"username":"admin","role":"ADMIN"}` |
| `GET /api/auth/me`（无 token） | `401` |

> `local` profile 的 `admin/admin123` 与开发密钥仅用于本地演示，不是真实秘密；生产走 env 注入。
