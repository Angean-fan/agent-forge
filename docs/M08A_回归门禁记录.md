## 二、迁移回退测试（`tests/test_migrations.py`）

在临时 SQLite 文件上逐步执行并逐级检查版本与表/列结构：

1. `upgrade head` → 版本 `0003`；表 `project/spec_version/platform_session` 存在；`project` 含 `requirement_text` 列。
2. 写入一行 `project` 数据。
3. `downgrade 0002` → 版本 `0002`；`requirement_text` 列**被删除**（该列与其中数据一并丢失）；其余表保留。
4. `downgrade base` → 受管表全部删除，`alembic_version` 无版本号。
5. `upgrade head` → 表重建，版本回到 `0003`，但**之前写入的行已随回退丢失**（查询为空）。

**结论**：回退会删除对应版本新增的数据（列级回退删列及其数据；base 回退删表）。测试通过。

## 三、TestClient 依赖决策：替换 `httpx` → `httpx2`

- **触发**：M02—M04 起 `fastapi.testclient` 持续告警 `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated; install httpx2 instead`。
- **兼容性验证（隔离 venv）**：新建 venv 仅安装 `fastapi + httpx2 + pytest`（**不含 httpx**）→ `TestClient` 正常，1 passed，**无弃用告警**；确认 `httpx=False, httpx2=True`。
- **决策**：替换。`uv remove --dev httpx` + `uv add --dev httpx2` → dev 依赖变为 `httpx2>=2.13.1`（解析：httpx2 2.13.1 / httpcore2 2.13.1 / truststore 0.10.4），`uv.lock` 更新。
- **替换后**：`uv run --locked pytest` → **68 passed，告警消失**；代码/测试无直接 `import httpx`，无连带影响。
- **备注**：`httpx2` 为 Starlette 弃用提示指向的替代包；若后续 Starlette 改变该建议，需复查（当前已消除告警）。
