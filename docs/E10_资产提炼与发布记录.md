## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：建立**人工审核的资产提炼与回灌流程**：从高频 Agent Gap/修复案例挑可复用代码，去项目化、
  整理依赖与调用契约、补独立测试，发布为不可变资产并刷新索引，测量成本/质量收益。
- **Context**：R06A—R06D 已建索引；E10 专注"从通过验收的个案到可靠公共资产"的治理闭环。
- **Constraints**：只从**已通过项目完整 Runner 验收**且来源/许可证可审计的变更提炼；**已验收 ≠ 通用性已证实**，
  **不得自动入库**；流程 `提名 → 来源/许可证/敏感信息审查 → 提取最小单元 → 声明契约 → 独立+跨 Profile 契约测试
  → 人工批准 → 发布新 asset ID/version/checksum → 原子更新/重建 FTS5`；失败候选留审查区；运行中 Agent **无公共仓库
  写权限**；不原地改已发布版本；不凭方法名/向量相似度提覆盖率；首版不引入向量库。
- **WhenDone**：提炼出一个通用 Method Unit（保留候选 Patch、审核决定、独立回归、发布 manifest、源码哈希、
  索引版本、旧锁重放证据）；复测同场景能**优先匹配并安全装配**新资产；测量对比复用指标；**拒绝**一个不具通用性/
  来源证明/安全测试的候选，证明不污染公共库。

## 输入 / 输出契约（`asset_distillation.py`）

- **`Candidate`**：`asset_id/version/origin_run_id/origin_acceptance_passed/provenance/license/generality/
  cross_profiles/manifest(方法契约字段)/source_file/source_text/test_file/test_text`。
- **`review_candidate(candidate, *, known_profiles) -> CandidateReview`**：确定性门禁——
  来源未过完整验收 / 缺来源 / 许可证不明 / 未声明通用性 / 缺独立测试 / 缺跨 Profile 契约测试（或未覆盖已知 Profile）/
  **含秘密或项目私有标记** → **拒绝**（`approved=False` + 结构化 `issues`/`scrub_findings`）。
- **`scrub_source(text)` / `sensitive_findings(text)`**：抽离密钥（秘密赋值/PEM/JWT/AWS）；项目私有标记（如
  `com.agentforge.template`）须**人工去项目化**后再审。
- **`publish_candidate(candidate, review, methods_root, *, index_path, approved_by, caller)`**：
  未审核/无批准人/**版本已存在** → 拒绝；否则写 `src/`+`tests/`+`manifest.json`（校验和覆盖内容、`MethodUnitManifest`
  强校验）→ **原子 `build_index` 重建 FTS5 索引**（新 `index_revision`）。
- **`record_rejection(...)`**：被拒候选落 `methods/.review/`（**不进索引/公共库**）。
- **`assert_not_agent_writable(caller)`**：**运行中 Agent 无写权限**（仅离线人工工具可发布）。
- **`compare_metrics(before, after)`**：对比 `检索命中率/兼容通过率/实际复用率/验收成功率 + 模型调用量/费用/耗时`。
- CLI：`python -m agentforge_platform.asset_distillation`（默认方法根 `methods/`）。

## 设计

- **治理优先、非自动**：候选必须经确定性门禁 **且** 人工批准（`approved_by`）；不因"跑通过一次"入库。
- **不可变 + 原子**：新 `asset_id@version` 目录；已存在即拒（不原地改）；索引用 `build_index` 原子重建（可丢弃派生视图）。
- **敏感/私有即拒**：秘密与项目私有标记是**硬门禁**；去项目化由人工完成（工具不擅自改写语义）。
- **Agent 隔离**：发布入口校验调用方；运行中 Agent 无公共库写权限。
- **可度量**：发布前后复用指标对比，供人工判断收益；首版沿用 FTS5，不引向量库。

## 剩余风险 / 下一步

- **候选提名仍偏人工**：`Candidate` 由人工/工具从已验收 run 的 gap/patch 构造；自动"高频缺口聚合提名"留待后续。
- **独立回归未真正编译**：独立/跨 Profile 契约测试以**文本资产**形式发布与门禁校验，编译级回归随装配/Runner 接入。
- **度量口径为输入**：`ReuseMetrics` 由调用方汇总（可接 R27 评估数据）；本步提供对比结构而非采集器。
