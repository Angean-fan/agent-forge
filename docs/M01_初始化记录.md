## 设计决策与偏离说明

1. **Python 版本锁定 3.12**：文档允许 3.11 或 3.12。本机具备 3.12.10，选择 3.12 并在 `.python-version` 与 `requires-python=">=3.12,<3.13"` 中锁定。已于 2026-10-11 经开发者确认继续使用 3.12。
2. **目录范围**：仅创建 `platform-api/`、`platform-ui/`、`docs/`。未创建 `worker/`、`runner/`、`profiles/`、`templates/`、`capability-packs/`、`schemas/`、`recipes/`、`integrations/`——这些在对应步骤（M06/M08/M09/M11/M16/M20 等）落地时再建，符合 Constraints「仅创建实际将用到的目录；不为目录整齐一次性创建空框架」。
3. **Python 包命名 `agentforge_platform`**：置于 `platform-api/src/`（src 布局）。后续 worker/runner 若为独立 Python 包，可避免与 `agentforge` 顶层命名冲突。
4. **Node 测试入口零依赖**：使用 Node 内置 `node --test`，未引入 Vitest 等；Vue/Vite/Vitest 在 M25 前端落地时按 Profile 引入。因此本步无 `package-lock.json`。
5. **依赖锁定**：`pyproject.toml` 声明 `pytest`、`ruff`（dev 组），精确版本由 `uv.lock` 承载；未手工硬编码未经解析的版本号。
