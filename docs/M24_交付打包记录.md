## 交付物（写入 run 目录并打入 ZIP）

`source.zip` 内包含：`backend/`、`frontend/`、migration、`.env.example`、Dockerfile、`compose.yaml`、`README.md`、`spec.json`、`asset-lock.json`、`API.md`（接口说明，由契约生成）、`verification.json`、`cost-report.json`、`EXTERNAL_SERVICES.md`。

- **排除**：`.env`/`.env.*`（保留 `.env.example`）、`node_modules`、`target`、`dist`、`build`、`__pycache__`、`.git`、`.venv`、`.DS_Store`、`*.log`、`logs`、`*.zip`。
- **密钥扫描**：逐块扫描文件全文（包括跨块边界）；`sk-…`、`-----BEGIN … PRIVATE KEY-----`、`AKIA…` 命中即 `SECRET_DETECTED`，不产出 ZIP。符号链接以 `UNSAFE_PACKAGE_PATH` 拒绝，避免打包 run 目录外的文件。
- **体积上限**：`AGENTFORGE_PACKAGE_MAX_FILES` / `_MAX_BYTES` / `_MAX_ZIP_BYTES`；超限 `PACKAGE_TOO_LARGE`，**仅清理本 run 暂存 ZIP**（`unlink`），保留失败事件与记录。
- **verification.json**：`validation_scope="MVP"`、`verified`/`label`（`已验证`/`未验证`）、`verify_overall`/`accept_overall`/`mysql_digest`、逐项 `checks` 与 `acceptance_cases`。
- **cost-report.json**：`draft_phase`（生成前草稿，`run_id` 为空）与 `generation_phase`（`run_id`）两桶，整数微单位 + `unknown_calls`；缺核定价格记 UNKNOWN。
- **EXTERNAL_SERVICES.md**：本 MVP 无第三方服务 → 明写"**无须配置**"。

## 图集成

`package_or_fail`：`verify` 结果及四项必检共同决定 `ok`；无论成功/失败都打包含报告（失败包 `verified=false`/`未验证`）；`ok` → `SUCCEEDED`，否则 `FAILED`（记 `error_code`）。打包失败写入具体错误码（如 `PACKAGE_TOO_LARGE`、`SECRET_DETECTED`、`UNSAFE_PACKAGE_PATH`）。ZIP 记为 run 的 `artifact`（含 sha256、`verified` 与运行状态一致）。
