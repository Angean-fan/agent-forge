## 4. 关键设计

- **双重开关**：`AGENTFORGE_MODULE_PARALLEL_ENABLED` **且** `AGENTFORGE_MODULE_PARALLEL_APPROVED`；
  缺任一 → 回退 **F07 串行模式**（父步语义不变）。
- **不以路径不重叠为安全证明**：同波除无依赖外，还须 **migration 命名空间**与 **DTO 命名**不相交；否则自动后置串行。
- **暂存隔离 + 合并检测**：每模块独立暂存目录；最终合并按路径+内容哈希检测冲突（禁止覆盖）。
- **并发预算**：`BudgetPool` 加锁预留/结算/释放 → **不双扣**；**任务幂等**（已完成模块跳过）。
- **失败隔离**：单模块异常不拖垮同波其他模块。
- **不延伸**：不做公开的任意任务委派；真实并发 DB/队列扩容不在本步。
