## 装配流程（`assemble`）

1. **COPY 基础模板**：遍历 `templates/` 复制到暂存目录；**先跳过排除项**（`manifest.json`、`node_modules/target/dist/build/__pycache__/.git`、模板 README），再做**符号链接检查**（含则拒绝）与越界检查。
2. **渲染能力包**：按锁清单里每个 `capability-pack`，用 `render_pack_files` 渲染到 `target_dir`（`backend` / `frontend`）；随后 `inject_dependencies` 写入 pom 依赖注入点。
3. **写交付物**：`asset-lock.json`（锁清单）+ `README.md` 草稿（由 spec/契约确定性生成，无 LLM）。
4. **核对并提交**：统计文件（路径/SHA-256/大小）→ 计算 `manifest_hash` → **暂存目录原子重命名**为最终目录。

## 守卫（写文件前）

- **安全路径**：拒绝绝对路径、`..`、反斜杠、控制字符；写入前再次确认目标在输出根内。
- **无覆盖**：同一路径（`subdir/rel`）二次写入 → `ASSEMBLY_ERROR`（不做覆盖）。
- **限额**：`AssemblyLimits(max_files=2000, max_file_bytes=2MiB)`，超限即拒。
- **符号链接**：模板内容含符号链接 → 拒绝（防逃逸）。
