## 5. 关键设计

- **规则优先、零模型**：模块 = 实体（单/多任务）；依赖边来自 `relations`（child→parent）；全程无模型调用。
- **共享文件唯一 owner**：`PageResult.java` / `MybatisPlusConfig.java` / `ConstraintViolationAdvice.java` 归
  `shared_owner="template"`，**任何业务模块都不得声明**（越权即 issue）。
- **唯一写入权**：模块 `owned_paths` 为**具体文件**（无通配符）；两模块重叠/声明对方目录/共享文件 → 拒绝。
- **生效权限**：`task.allowed_paths ∩ module.owned_paths`，**空交集阻塞**；任务路径不落任何模块 → 越界阻塞。
- **兼容与隔离**：`modules.json` 独立 schema 版本，不触碰老 `RunTask` 与 `asset-lock`；本步**不接入生成图**
  （模块 Agents 关闭时走旧任务调度 → 单模块旧 Task 路径无变化）。
