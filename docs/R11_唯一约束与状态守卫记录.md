## 设计

- **约束由契约驱动、单一渲染路径**：唯一约束只来自契约 `unique_constraints`，由 CRUD 包 migration 渲染；**不新增第二套“约束能力包”** → 不会重复建约束或忽略契约字段。
- **并发兜底**：`UNIQUE (activity_id, owner_id)` 由数据库强制；`DataIntegrityViolationException` 经 `ConstraintViolationAdvice` → 409，**不返回成功**。
- **状态服务端检查**：`Service.create` 经外键读父实体，父状态命中 `blocked_status` → 409；前端防重非必需。
- **哈希稳定**：`status_guards` 为空时不参与 canonical hash（同 `method_requests` 处理），旧 spec 冻结 hash 与契约夹具不变。
- **版本策略**：仅后端包升 0.3.0（前端 0.2.0 保持不变）；旧版本继续发布可重放；四组合 `asset-lock` 样例随之更新。
