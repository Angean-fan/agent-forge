## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：实现租约接管、LangGraph checkpointer 和按任务 hash/幂等键恢复执行。
- **Context**：节点重放不能保证外部副作用“恰好一次”，必须核对已提交任务、文件 hash 与账本。
- **Constraints**：恢复时不得重复提交源码或盲目重发状态不明的模型请求；UNKNOWN 调用须人工/账单对账；**同一 run 的既有产物不得被覆盖**；checkpoint 不得保存密钥；恢复必须**复用原 `asset-lock` 的 Method Unit**，不因 FTS5 索引更新而重选。
- **WhenDone**：在装配完成/模型在途/Runner 验证中三个节点各模拟崩溃，重启后一致且可解释；**已提交任务不重做，未知调用不重复收费**。

## 输入 / 输出契约

- **`claim_run(db, worker_id, *, include_recovery=True)`**（`runs.py`）：先领 `QUEUED`；无则**接管在途但租约已过期**的 `PLANNING/GENERATING/VERIFYING`（`RECOVERABLE_STATUSES`）run；原子更新防双领。
- **`unsettled_call_count(db, run_id)`**：本 run 中 `RESERVED/UNKNOWN` 的模型调用数。
- **`record_task_once(db, run, task_id, status)`**：幂等登记任务（同 run+task_id 一行），重放不违反唯一约束。
- **`run_generation(context, run_id)` 恢复分支**：run 处于可恢复在途状态时——
  - 若 `unsettled_call_count>0` → 落 `FAILED / NEEDS_RECONCILIATION`（**不盲目重发**，账本保留）；
  - 否则回退到 `PLANNING` 并**节点幂等重放**（复用已提交任务与产物）。
- **节点幂等**：`resolve_assets` 复用 `run_dir/asset-lock.json`（不重选方法）；`plan_tasks` 复用 `run_dir/task-plan.json`（不重复调用规划模型）；`assemble` 见已完成装配即跳过（**不覆盖既有产物**）；`package_or_fail` 见 `source.zip` 即跳过重打包。
- **`GenerationContext.checkpointer`**：可选 LangGraph checkpointer；`build_graph` 以其编译，`run_generation` 用 `thread_id=generation:<run_id>`。检查点存于图状态（**不含密钥**）。

## 设计

- **租约接管**：崩溃 worker 的租约到期后，新 worker 可接管在途 run；仍以数据库时间与乐观条件保证不双领。
- **对账优先于重放**：状态不明（`RESERVED/UNKNOWN`）的调用意味着 Provider 可能已处理——**拒绝自动续跑**并要求对账，杜绝重复收费；账本原样保留。
- **幂等重放**：恢复把 run 回退到 `PLANNING` 后从起点重放，但**每个副作用节点自判“已完成即跳过”**——装配/计划/锁均复用磁盘产物，验证等只读节点可安全重跑；任务登记 `record_task_once`。
- **产物不覆盖**：`assemble` 仅在无“已完成装配（asset-lock.json+spec.json 且无半成品暂存）”时才重建；`package_or_fail` 见既有 ZIP 即不重打包。
- **checkpointer**：可选启用；检查点仅含状态（spec/lock/契约/哈希），不含密钥；作为“恰好一次”的补充，核心保证仍由 DB 任务账本 + 幂等节点提供。

## 风险 / 下一步

- **恢复为状态式重放**：核心“恰好一次”由 DB 任务账本 + 幂等节点 + 对账门禁保证；LangGraph checkpointer 为可选补充（同一 thread 重入语义与状态式恢复并行时不重复执行副作用）。
- **`NEEDS_RECONCILIATION` 为人工闸**：需运维比对 Provider 账单后清理 `RESERVED/UNKNOWN` 行再重跑；本步不提供自动对账 UI。
- **下一步 R24**：预算暂停与经确认的恢复（`PAUSED_BUDGET`、可追溯预算调整、`POST /api/runs/{id}/resume`；不静默换廉价模型；未授权/未加预算恢复被拒）。
