## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：Runner 接收装配产物，执行静态清单检查、`mvn test/package`、`npm ci/build`，生成结构化结果。
- **Context**：依赖 M09、M15、M16；技术文档第 7 节检查层与 PASS/FAIL/NOT_RUN；TS 类型检查执行模板真实命令。
- **Constraints**：仅运行固定任务；时间/内存/进程及依赖代理受控；缺少命令、依赖离线或没有执行测试一律不能算 PASS；日志脱敏并截断。
- **WhenDone**：正常 Task 工程构建检查真正通过；注入 Java 编译错误返回 `FAIL/BUILD_FAILED`；缺少网络依赖正确归类基础设施故障。

## 校验管线（`POST /verify`）

对装配产物执行固定检查，输出 `{artifact_dir, overall, checks[]}`，每项 `{name,status,error_code,exit_code,detail,log_excerpt}`：

| 检查 | 说明 | 载体 |
|---|---|---|
| `static_manifest` | 必需文件齐全（pom/package-lock/compose/asset-lock/migration） | Runner（Python，无容器） |
| `backend_test` | `mvn -B test`；**无 `Tests run:` 则 `NOT_RUN/NO_TESTS`** | 受限容器 |
| `backend_build` | `mvn -B -DskipTests package` | 受限容器 |
| `frontend_build` | `npm ci` + `npm run type-check` + `npm run build`（固定脚本、模板真实命令） | 受限容器 |

**失败分类**：构建/测试错误 → `FAIL/BUILD_FAILED`；依赖离线、命令/镜像缺失等 → `NOT_RUN/INFRASTRUCTURE`；超时 → `NOT_RUN/TIMEOUT`。
**日志**：`redact`（password/secret/token/api_key/JWT → 占位）+ `truncate`（4000 字符，保留首尾）。
`overall`：任一 `FAIL` → FAIL；否则任一 `NOT_RUN` → NOT_RUN；否则 PASS。

## 实测（Docker Desktop，执行镜像 `agentforge/runner-executor:demo-0.1`）

用 M15A 装配出的**普通 Task 工程**（`/verify` 全量）：

| 场景 | overall | 逐项 |
|---|---|---|
| 正常工程 | **PASS** | static_manifest PASS；backend_test PASS(exit 0，测试真实执行)；backend_build PASS；frontend_build PASS |
| 注入 Java 编译错误（`TaskController.java` 追加非法语句） | **FAIL** | backend_test `FAIL/BUILD_FAILED`；backend_build `FAIL/BUILD_FAILED` |
| 依赖离线（`RUNNER_CONTAINER_NETWORK=none`，空缓存） | **NOT_RUN** | static_manifest PASS；backend_build `NOT_RUN/INFRASTRUCTURE` |

每次运行后 `docker ps -a` 无残留容器（`--rm` 清理）。

平台/Runner 测试：runner **21 passed, 2 skipped**（分类/脱敏/静态清单/`/verify`），`ruff` 全绿。

## 剩余风险 / 偏差（如实记录）

- **依赖来源**：执行容器默认 `--network none`；本机**无受控依赖代理 / 未预热依赖缓存**，故"正常构建 PASS"实测时用 `RUNNER_CONTAINER_NETWORK=bridge` 临时放行公网下载（**偏离"公开网络默认阻断"**）。生产应以**受控依赖代理**或**镜像内预热的只读依赖缓存**替代。
- 只读根下 Maven/npm 可写缓存指向容器内 tmpfs（`/tmp`，1g，随容器销毁）→ 每次运行重下依赖，慢且不可复现；应改为预热缓存。
- 执行镜像未推送 registry；基础镜像仍为可变 tag。

## WhenDone 逐项判定

| 条目 | 判定 | 依据 |
|---|---|---|
| 正常 Task 工程构建检查真正通过 | ✅ 满足 | `/verify` overall PASS（backend_test 真跑测试、backend_build、frontend_build） |
| 注入 Java 编译错误 → FAIL/BUILD_FAILED | ✅ 满足 | 注入后 backend_test/build 均 `FAIL/BUILD_FAILED` |
| 缺少网络依赖归类基础设施故障 | ✅ 满足 | `--network none` 下 `NOT_RUN/INFRASTRUCTURE`（非 BUILD_FAILED） |
