## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：定义用户需**申请/填写**的账号、标识、密钥、回调、白名单等**结构化待办**，生成
  `.env.example` 与 `EXTERNAL_SERVICES.md`。
- **Context**：依赖 E01/E02；技术文档 §4/§6 的 External Requirement 字段
  `kind/secret/required_in_modes/acquisition_url/target_file/env_name/config_path/validation_rule/docs_verified_at`。
- **Constraints**：`secret` 与 `required` **独立**；AppID、公钥**不默认当秘密**；程序生成实际配置映射与
  固定指南，仅在需要 AI 通俗解释**已验证配置事实**时调用 **DeepSeek**，不用 Qwen 原始输出直接面向用户；
  同名变量冲突**拒绝/命名空间化**；真实凭据绝不入 spec/Prompt/ZIP/日志。
- **WhenDone**：从 pack manifest 自动生成"申请什么—在哪里申请—填写哪里—如何验证"的指南；
  环境变量与代码绑定 **1:1**；秘密扫描通过。

## 输入 / 输出契约

- **清单结构化字段（`ExternalConfigItem`，向后兼容 E01/E02 的极简写法）**：
  `env_name/required/secret/description` + `requirement_id/name/kind/required_in_modes/config_path/
  target_file/acquisition_url/acquisition_steps/validation_rule/docs_verified_at`（均可选）。
  - `secret`/`required` 独立；`required_in_modes ⊆ {mock,live}`（默认 `[mock,live]`）。
  - 校验：`env_name` 大写环境变量名；`kind`/`config_path`/`target_file` 安全标识与相对路径；
    `acquisition_url` 须 http(s) 且**不得内嵌凭据**（无 `user:pass@`）。
  - mock-only 规则细化：**仅在"秘密且在 mock 模式下必需"时拒绝** → live-only 秘密可声明（AppID 非秘密）。
- **`external_requirements.py`（新）**：
  - `collect_requirements(packs)`：跨 pack 汇总；同名变量**语义冲突抛 `ASSET_CONFLICT`**，语义一致去重。
  - `binding_issues(requirements)`：`env_name ↔ config_path` **1:1**（同一配置键不得被多变量占用；env 非空）。
  - `generate_env_example` / `generate_external_services_md`：确定性产物；秘密值**留空**，非秘密填
    保留域占位（`example.invalid` / `example-app-id` / `CHANGE_ME`）。
  - `scan_for_secrets(text)`：秘密命名变量带非空值、PEM 私钥、JWT、AWS Key。
  - `build_docs(packs)` → `ExternalDocs`；`require_clean_docs` 对绑定/扫描问题抛 `ASSET_CONFLICT`。
  - `render_user_explanation(docs, *, explain=None)`：默认**确定性模板**；`explain`（DeepSeek）只接收
    **脱敏结构化事实 JSON**，须仅复述事实（无模型调用默认路径，免费）。

## 设计

- **程序生成、模型只解释**：配置映射与指南由程序**确定性**生成；`explain` 是可选缝，仅把**脱敏事实**
  交给 DeepSeek 生成用户可读说明，不改事实/权限/费用/检查状态；默认不调用任何模型，Qwen 输出不直接面向用户。
- **秘密边界**：秘密值留空、非秘密用保留域占位；`acquisition_url` 禁止内嵌凭据；秘密扫描对"秘密变量带值/
  PEM/JWT/AWS Key"命中即拒 → 真实凭据不进入产物/日志/ZIP。
- **1:1 绑定与冲突**：`env_name` 全局唯一（语义一致去重、语义不同拒绝）；`config_path` 不得重复。
- **版本不变式**：`0.3.0` 为新增版本，`0.2.0`/`0.1.0` 字节不变；默认取最高版本，`id@version`/`pins` 固定复现。
