## 对应 Goal / Context / Constraints / WhenDone

- **Goal**：为**由 AgentForge 生成**且携带资产锁的项目提供"确认变更 → 冻结新规格 → 影响分析 → 最小变更"工作流。
- **Context**：依赖 R13/R17/R23 和 `asset-lock.json`；技术文档 §6 要求模板版本与契约变更可追溯。
- **Constraints**：**起步只支持 AgentForge 自有产物**；变更意图/用户可读反馈由 **DeepSeek** 处理，技术影响分析由
  **Qwen** 处理（仅已确认任务）；不承诺任意仓库改造；**契约改变须重新冻结并回归**，**旧 run 不得原地修改**；
  升级优先**复用锁定的旧方法资产**；契约改变必须**显式重新检索/重新冻结新锁**，不得直接改旧 ZIP 的方法引用。
- **WhenDone**：一个已完成 Task 项目增加经过确认的字段/业务规则后，**生成新版本并保留旧 ZIP/报告**；
  迁移与回归测试通过。

## 输入 / 输出契约（`iteration.py` + 运行 API）

- **`artifact_eligibility(run_dir)` / `load_artifact(run_dir)`**：源运行目录必须含可解析的 `spec.json` +
  `asset-lock.json`（AgentForge 自有产物），否则抛 **`ITERATION_INELIGIBLE`(422)**。
- **`classify_change(old_spec, new_spec) -> ChangeImpact`**：确定性影响分析——**契约是否改变**
  （`contract_hash`，退化时用结构签名）+ 实体/字段/规则差异与摘要。
- **`plan_iteration(old_spec, old_lock, new_spec) -> IterationPlan`**：
  `relock_required = impact.contract_changed`；按新规格 `method_requests` **复用锁定的旧方法资产**、
  其余标记 dropped；notes 明确"旧 run/ZIP/锁不原地修改 + 契约改变须重新检索冻结"。
- **`POST /api/runs/{id}/iterate`（owner）**：校验 `SUCCEEDED` + AgentForge 产物 → 冻结**新规格版本** →
  新建 run → 返回 `IterationView`（新旧 run id、新 spec 版本、`contract_changed/relock_required`、复用方法、notes）。
  **全程不写旧 run 目录**。
- **模型缝（默认确定性，不调用）**：`refine_change_intent(explain=…)`（DeepSeek 只述脱敏事实）；
  `analyze_impact(planner=…)`（Qwen 只对已确认变更提最小任务建议）。
- `errors.py` +`ITERATION_INELIGIBLE`。

## 设计

- **只支持自有产物**：以 `spec.json` + `asset-lock.json` 作为"AgentForge 产物"证据；不承诺任意仓库改造。
- **契约变更加锁**：`contract_hash` 变化即 `relock_required=True`；新 run 重新解析并写入各自的 asset-lock，
  **不**改旧 ZIP 的方法引用。
- **不可变**：迭代只创建**新** spec 版本与**新** run；旧 run 的 `spec.json`/`asset-lock.json`/ZIP 字节保持不变（测试以 SHA-256 断言）。
- **优先复用**：升级优先复用锁定的旧方法资产；不再需要的标记 dropped。
- **模型边界**：用户可读反馈走 DeepSeek、技术影响走 Qwen，均为可注入缝且只接收脱敏事实/已确认任务。

## 剩余风险 / 下一步

- **模型缝未实测**：DeepSeek 变更意图/用户反馈与 Qwen 影响分析为可注入缝，真实调用与路由断言待带预算里程碑。
- **迭代仍走完整重生成**：本步以"新规格版本 + 新 run"实现最小变更；更细的"仅改受影响实体/迁移差异增量"随装配接入。
- **asset-lock 与 spec 解耦**：当前 lock 按 Profile 解析、与具体字段无关，故新旧锁内容可能一致；`relock_required`
  保证的是**显式重新冻结**语义，而非必然产生不同字节。
