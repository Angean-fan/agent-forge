# task-crud-frontend-js

Vue 3 + **JavaScript** 的单实体 CRUD 前端能力包（对应 `demo-js-mp` Profile）。
由 `task-crud-frontend@0.1.0` 的 TS 基线派生，**只替换真正不同的前端结构**（去类型、`.js` 目标），
接口路径、分页/搜索行为与 TS 版一致。

- 渲染目标：`frontend/`（`src/api/*.js`、`src/views/*.vue`、`src/router/modules/*.js`、`test/*.spec.js`）
- 依赖：无额外 npm 依赖（复用模板既有依赖）
